About This Project

Abuja Meal Finder is a WDD 231 final project built to help locals and visitors discover the best food spots across Abuja, Nigeria. From roadside suya to upscale intercontinental dining, this directory showcases 20+ restaurants with real details on category, price, and location.

This site was built using semantic HTML5, modern CSS, and vanilla JavaScript ES Modules. No frameworks were used. All restaurant data is stored locally in JSON and fetched using the Fetch API.
